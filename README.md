Music pack for Breeze of lewdity, music from https://www.youtube.com/@ProjetosCamposSoltos who had made this wonderful soundtrack so befitting of the game. 

Instructions:

1. Download soltosoundtrack.zip
2. Put the soundtrack folder in .breeze/packs
3. Import the json found in the zip
Enjoy!

Alternate upload:

1. Download the online version .json
2. Use the import button in the breeze ui and select the json
3. Done!
